🇯🇵 Japan Highway SA/PA Offline Map

Offline KML maps of Japanese highway Service Areas (SA) and Parking Areas (PA), made for hitchhiking and road trips.

The locations are extracted from the "OpenStreetMap-derived Japan POI dataset" (https://github.com/gpsnmeajp/nearest_pois_jp/blob/main/japan_pois.py), specifically the "japan_pois.py" file from the ""nearest_pois_jp"" (https://github.com/gpsnmeajp/nearest_pois_jp) GitHub repository.

📍 What's included

867 locations in total:

- 🛣️ 252 Service Areas (SA)
- 🅿️ 523 Parking Areas (PA)
- 🚗 92 additional SA/PA service locations

The map covers locations throughout Japan.

📥 Files

Japanese names

"Japan_SA_PA_OSM_CoMaps_Japanese.kml"

Names are displayed in Japanese, for example:

«蓮田SA (下り)»

Japanese + Romaji

"Japan_SA_PA_OSM_CoMaps_Japanese_Romaji.kml"

Names are displayed in Japanese with romaji:

«蓮田SA (下り) (Hasuda SA (Kudari))»

📱 Using with OsmAnd

1. Download one of the ".kml" files.
2. Import the KML into OsmAnd.
3. The SA/PA locations can be displayed as a map layer.
4. Download the Japan offline map in OsmAnd beforehand so you can use everything without an internet connection.

🚗 Why?

I made this because I wanted an easy way to see all the highway SA/PA locations while hitchhiking around Japan, without needing an internet connection or searching for individual locations.

SA and PA can be useful for hitchhikers because they are places where travelers, drivers and highway traffic are concentrated.

⚠️ Important

This is an unofficial community-made map.

The underlying data comes from an OpenStreetMap-derived dataset, so locations may be incomplete, inaccurate, or outdated. Please check important information such as opening hours, accessibility and highway access before relying on a location.

🗺️ Data

The SA/PA locations are derived from OpenStreetMap contributors' data through the "japan_pois.py" dataset in the ""nearest_pois_jp"" (https://github.com/gpsnmeajp/nearest_pois_jp) project.
